# CricBeat (CricBeatGame) — Direct-to-Consumer Web Hub (MVP)

Welcome to the **CricBeat (CricBeatGame)** repository. This project serves as the lightweight Direct-to-Consumer (D2C) landing page, game rules showcase, product details hub, and Razorpay checkout engine.

## 🚀 Key Features
- **Dark-Theme Gamified UI**: Built with glassmorphism and modern mobile-game styling.
- **Razorpay Integration**: Native 1-tap UPI deep-linking and dynamic QR code generation.
- **Zero-Server Hosting**: Deployable directly via GitHub Pages or Vercel.
- **Embedded Game Education**: Integrated YouTube gameplay video link and rules breakdown.

## 🛍️ Tech Stack
- **Frontend**: HTML5, Vanilla CSS3 (Game-inspired custom properties), JavaScript (ES6+).
- **Payments**: Razorpay Standard Checkout SDK.
- **Deployment**: GitHub Pages / Vercel.

## 🛠️ Development & Kiro Setup
1. Clone this repository locally or open in **Kiro**.
2. Run `npm install` and `npm start` to preview locally on `http://localhost:3000`.
3. To test Razorpay payments, update `key` in `js/checkout.js` with your Razorpay Test Key (`rzp_test_...`).
